# 🛒 Grocery Sales Retail Analytics

## 📌 Project Overview

This is a Machine Learning project based on Grocery Sales
Retail Analytics.

The main objective of this project is to predict the
**Profit** of a grocery order using different sales and
order-related features.

---

## 📊 Dataset

Dataset Name:

`Grocery_Sales_Retail_Analytics_24bcads054.csv`

The dataset contains grocery sales and order information.

### Dataset Details

- Total Records: 9,994
- Total Columns: 11
- Target Variable: Profit
- Problem Type: Regression

---

## 🎯 Objective

The main objective of this project is to:

- Analyze grocery sales data
- Prepare data for Machine Learning
- Train a Regression model
- Predict grocery order profit
- Create a user-friendly web application

---

## 🤖 Machine Learning Model

The project uses:

**Random Forest Regressor**

Random Forest is used to predict the expected profit
based on the given order and sales information.

---

## 🔍 Features Used

The following features are used for prediction:

- Category
- Sub Category
- City
- Region
- State
- Sales
- Discount
- Order Year
- Order Month
- Order Day
